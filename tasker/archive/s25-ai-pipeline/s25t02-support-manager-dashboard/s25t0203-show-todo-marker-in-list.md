# Show (todo) marker in `list` output

Show `(todo)` marker on tasks in the `list` output.

- Marker only on tasks explicitly added via `tasker todo`
- Children of TODO tasks are NOT marked (they inherit TODO status for filtering only)
- `(todo)` and `(q)`/`(p)` coexist; `(q)`/`(p)` is always rightmost
- Styled in `[cyan]`, same as existing markers
